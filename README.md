## How It Works

### Encryption
The application converts normal text into Base64 encoded text using JavaScript.

Example:

hello
↓
aGVsbG8=

### Decryption
The encoded Base64 text can be decoded back into readable plain text instantly.

Example:

aGVsbG8=
↓
hello
