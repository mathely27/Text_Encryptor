## 🧠 How It Works

### 🔐 Encryption

Normal text gets converted into Base64 encoded text.

```txt
hello
↓
aGVsbG8=
```

---

### 🔓 Decryption

Encoded Base64 text is converted back into readable plain text.

```txt
aGVsbG8=
↓
hello
```
